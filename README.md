# 💍 ElegantAdoronment — Jewelry Shop Website

Welcome to **ElegantAdoronment**, your one-stop destination for all things sparkly! This is a modern jewelry e-commerce web app showcasing a wide range of jewelry — from timeless classics to trendy statement pieces.

## ✨ Features

- 🛒 Browse all types of jewelry: necklaces, rings, bracelets, earrings, and more
- 🔍 Smart search functionality to find your perfect sparkle
- 💖 Wishlist / Add to Cart options
- ⚡ Built with a smooth, fast front-end using React.js

## 🛠 Tech Stack

- **React.js** — Front-end framework
- **JavaScript (ES6+)** — Core language
- **Mui** — For sleek and elegant UI styling
